# About Avix Digital — HTML preview

Open `index.html`, or run `node serve.cjs` here and visit http://127.0.0.1:4173.

This preview is exported from the actual About Hero Elementor widget's default PHP rendering. Its stylesheet, script, fonts, logo and check badge are copied under `widget-assets/`. It contains a full-width hero and no header.

The revised heading caps at 62px on desktop, and scales between 26px and 36px on phones. Spacing and tile size compact on shorter screens so the default booking button and marquee fit within the first viewport. Larger text, longer replacement copy and short landscape windows can make the section grow.

The button retains the homepage pill treatment, uppercase Inter label and orange arrow circle, with a dark surface for clear contrast. The Avix logo has a white tile. Shopify, Webflow, WordPress and custom-code marks flow through the logo and emerge as the exact supplied green scalloped check SVG.

The animation measures each platform group, supports pause/resume, respects reduced motion, and pauses offscreen. A static accessible platform list remains available without JavaScript; phones also show it when room permits.

The installable widget is included in Avix Digital Elementor Widgets 1.9.0. See `ABOUT-HERO.md` in the plugin package for installation and editable controls.

Verification records and desktop/phone screenshots are supplied in this preview folder. Real WordPress 7.1.2, Elementor 4.3.3 and Chrome were used for integration checks. No changes have been published to avixdigital.com.
